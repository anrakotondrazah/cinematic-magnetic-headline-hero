# Cinematic Magnetic Headline Hero

A stunning hero section with magnetic text effects and cinematic transitions. Perfect for creative agencies and design studios.

## Features

- Magnetic headline effect on hover
- Cinematic reveal animations
- Responsive navbar with mobile menu
- Smooth transitions with CSS
- React + Vite + Tailwind CSS

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- TypeScript
- Lucide Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
```
